# Word Jump Obby

A single-file, mobile-friendly vocabulary game inspired by the shared Roblox-style word obby. It uses only HTML, CSS, and JavaScript, so it runs without a build step or external services.

## Courses

- **1.4 Geography** — continent, geography, physical map, political map, country, desert, lake, plain, mountain, river, island, valley, ocean.
- **Wolf! Wolf! Context Clues** — believe, delicious, feast, fond, lessons, remarkable, snatch, stories.
- **Unit 2 Poetry Words** — behave, express, flapping, feathers, poem, rhyme, rhythm. The school sheet marks these as practice words, not tested.
- **Unit 4 Energy** — energy, electricity, solar energy, water energy, appliance, fuel, wind energy, gasoline.

## Play

Open `index.html` in a browser. On a computer, move with **← / →** or **A / D** and jump with **Space** after answering correctly. On a phone or tablet, use the on-screen buttons.

## Publish with GitHub Pages

1. Create a GitHub repository and add `index.html` and this `README.md` at the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
4. GitHub will show the published site URL in the Pages settings when it is ready.
